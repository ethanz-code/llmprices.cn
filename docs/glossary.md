# 项目术语表（GLOSSARY）

本项目的统一语言。每个概念一个正名，_弃用_ 列出不再使用的旧黑话（历史文档与旧提交里仍会遇到，读到时按本表换算）。

2026-10-15 全库去黑话：旧词已从代码注释、文档、UI 文案中清零；本表保留旧词做换算索引。

## 计价

**基准价**：
new-api 系计价锚点 = `1e6/quota_per_unit × price`，两数取自站点 `/api/status`。
_弃用_：倍率基准价

**充值汇率**：
站点 `/api/status` 的 `price` 字段：1 美元额度卖几块钱人民币。与前端显示用的 `usd_exchange_rate` 是两回事。
_弃用_：充值口径

**计价分组**：
站方自己的分组名（default/vip…），不同分组倍率不同，同模型按分组各一条价。

**推算价（rule_only/inferred）**：
只有计费规则、单价按规则推算得出的价，非页面直接标价；与确认价相对。
_弃用_：规则价

**确认价（confirmed）/ 候选价（candidate）**：
price_status 两档：confirmed=证据闭环；candidate=有证据但不完整（含一切合成价）。

**真零价**：
输入输出双 0 且 price_status=confirmed 才算免费；站方 model_ratio=0 的 0/0 占位行不算。
_弃用_：真免费档

**阶梯计价（tiers）**：
按单次请求上下文长度分档计价；expr 站的缓存价藏在 tiers 里不在顶层（判有无缓存价两处都查）。

**加权单价**：
排序用的混合单价：输入 3 : 输出 1 加权折算 RMB；再加可靠性加权（最多让位 20%）。
_弃用_：综合价

**按重缓存用量折算的实付成本**：
站点综合分价格项的折算方式：输入约 96% 走缓存读、输出约 0.4%，缓存读写价直接决定成本；与计算器默认值刻意解耦。
_弃用_：缓存加权实付成本

**快照汇率**：
抓厂商价那一刻锁定的 USD→CNY 汇率；list_cny 等展示值都按它折好，展示时不重新换算。

**高于官价移除（above_official）**：
折合后任一轴比官价还贵的行采集侧直接移除不入快照；「站上有价库里没有」的高频真因，不是故障。
_弃用_：高于官价摘除

**虚假分组**：
站方虚挂「前台不卖」的分组；双信号判定（组内 ≥2 有价模型全同价 + 组内有 sanity 作废实证）后整组跳过，站方改价自动恢复。
_弃用_：占位组、假分组

## 采集与认证

**三条采集链路（价格链路/状态链路/公告链路）**：
一次站点采集的三个请求分支：价格接口、渠道状态接口、公告接口；共享认证但各有判定逻辑。
_弃用_：三腿、价格腿、状态腿、公告腿

**续签流程**：
token 自动换新的闭环；「流程死了」= 闭环失效（rt_ 被作废），需重新登录接入。
_弃用_：续签链

**主动续签 / 被动续签**：
主动=开抓前剩余寿命不足 1/6 或闲置满阈值就先续；被动=遇到 401 才续（配 24h 轮换 rt_ 会一天死一次）。

**续签熔断**：
站方回 REFRESH_TOKEN_INVALID 后打 dead_since 标记，所有链路跳过续签，防反复打已作废凭据被站方连带吊销。

**接入登录态**：
把用户浏览器里的登录凭证配进采集器（配续签/注入登录态）；接入后浏览器侧自动续签即作废。
_弃用_：接管

**登录限制**：
页面或接口要登录才给数据；标准动作=逐站开好登录页、登录后取凭证接入。
_弃用_：登录墙

**四键**：
sub2api 系注入浏览器登录态的 localStorage 四键：auth_token/refresh_token/token_expires_at/auth_user。

**会话绑定（SESSION_BINDING_MISMATCH）**：
sub2api 可开的指纹校验：出口 IP+UA 任一变化即 401 且吊销整个会话家族——接入登录态前必须先只读试探。

**auth_inject 三行**：
决定 token 以什么头注入三条采集链路请求的规则（每条链路一行），值里可用 ${access_token} 占位符，续签换新自动展开。

**采集出口（egress）**：
采集流量出口语义：直连优先、代理后备；面板 fallback_proxy 优先于 shell 环境变量。

**备用代理（fallback_proxy）**：
境内采不到国外站时配的后备代理；直连失败自动改走，恢复自动切回。
_弃用_：兜底代理

**换节点（proxy_switch）**：
备用代理也被拒时经 mihomo 在策略组里自动换「对该站实测可达」的节点；同域名 10 分钟冷却。

**试运行**：
管理台「测试采集」：默认不调 AI、零费用、不写库的跑一遍。
_弃用_：干跑

**热重载杀采集**：
dev server 跑着采集批时改后端代码，uvicorn 热重载把运行中任务全部打成「服务重启，任务中断」。

## 数据质量与清理

**对照核查（页面对照核查）**：
用页面渲染值（或载荷心算）与库内价格逐数核对，页面渲染值是唯一事实源；登录限制站按公式逐分组心算。
_弃用_：对拍

**监控模型清单**：
全站共用一份的监控模型名单（settings.monitor_models）；目录刷新自动补新、超 3 个月移出、手动删过不回加。
_弃用_：监控池、检测模型

**模型备选池**：
AI 调用侧的候选模型名单（ai/pool.py）：请求失败自动换下一个。

**孤儿清理**：
不在官方目录又无人在售的陌生名模型，连续 24 轮零覆盖才移出并记 dismissed。

**过期清理**：
按官方目录 release_date 把发布超 3 个月的模型自动移出监控模型清单。
_弃用_：老化清理

**dismissed**：
被手动移除/孤儿清理移出的模型名清单，防目录刷新时同名条目被自动加回。

**移除旧价（group_miss）**：
同一「站点:模型:分组」连续 3 轮无数据从快照移除旧价并发 group_removed 事件（认证失败整轮除外）。
_弃用_：摘除旧价、3 轮摘除

**沿用上次价格**：
本轮没采到的价由上一轮快照兜底沿用；连续 3 轮无数据就移除。
_弃用_：沿用旧价

**两轮确认（sanity）**：
站价对官价离谱时不立即作废：首轮挂 sanity_suspect 照常展示，下轮复现才作废，防误杀真数据。

**幻觉价 / 价格错配**：
AI 对证据里没有的模型编价 / 把别家真价安给目标模型；靠「名字+价格数字都在证据里」双重校验拦截。
_弃用_：张冠李戴

**歧义即弃权**：
别名匹配命中多个模型时放弃匹配并留痕，不猜测。
_弃用_：宁缺勿猜

**品牌归属校验**：
合并厂商定价页时按内置品牌表判归属；托管/转售他家的模型不进官方价目录。
_弃用_：品牌归属闸门

**官方价目录（catalog）/ 全量渠道价目录**：
前者=models.dev+厂商定价源合并的折扣基准；后者=catalog_all，8000+ 条仅供比价，不参与折扣。

**同源站去重**：
拉候选站 `/api/pricing` 模型名集合算签名，同签名判同一上游镜像站，每族留一个。
_弃用_：克隆去重

**新站发现**：
从公开聚合源拉候选中转站+探测可导入性；「忽略」存 discovery_ignored，已监控站忽略会连带删站点。
_弃用_：候选池（现称候选站列表）

**站点人气**：
每日采集：群链接、t.me 人数、SimilarWeb 月访问量与全网排名；拿不到不编数字。

**价格规则指纹（fingerprint）**：
只含价格相关字段的哈希，比对跨轮变化；AI 漂移的备注文本不参与，防「价格没变也发变更」。
_弃用_：价格口径指纹

## 评分与展示

**站点综合分**：
模型数据页每行 0–100 分：价格 35% + 渠道稳定 20% + 人气 30% + 配置完整 10% + 公告新鲜 5%，减数据滞后扣分；价格只在当前模型内横向比。

**数据滞后扣分**：
价格是沿用上次价格的（多半 token 过期）直接扣综合分，滞后 1 天起扣、满 4 天扣满 10 分。

**site_flags**：
各站配置完整度布尔集（监控模型/凭证/附加地址…），综合分「配置完整」一项的输入。

**检测点阵**：
每渠道一行 45 个点=最近 45 次检测，绿正常红异常；总览与详情页共用规格。
_弃用_：渠道点阵

**时段分桶 / 最差值降采样**：
画图用最差值降采样（每桶留最坏点，短暂故障不被抽丢）；数字统计用全量分桶——降采样会把均值压悲观。
_弃用_：时段桶、保峰抽稀

**监测范围**：
渠道状态只保留渠道名能对上「监控模型列表 ∪ 本站在售计价分组名」的行（严格归一匹配，不做后缀/前缀兼容）；对不上、监测集缺失都展示为空，任何情况不回退全量；站级可用率随之只算监测范围。
_弃用_：在售范围、在售口径

**默认排序**：
总览表默认行序：有价在前 → 综合分 → 可靠性加权单价 → 折扣 → 采集时间。
_弃用_：智能排序

**综合评分（intelligence_index）**：
Artificial Analysis 第三方评分（0–100），本站只引用不产出；对不上号的模型不显示。
_弃用_：智能指数

**输出速度**：
TPS 的页面叫法：模型每秒生成的 token 数。
_弃用_：出字速度

**事件折叠**：
同一轮扫描（检测时间相邻 120s 内）同站+同模型+同类事件折成一张卡。

**首页代表行（实时快照）**：
首页「最新价格」每模型只留加权单价最低的一条代表行，页头挂「实时快照」芯片。
_弃用_：首页精选行

**大橘**：
站点吉祥物橘猫插画组件族（DajuArt.tsx），空态、计算器、发现页出镜。保留原名。

## 事件与状态

**price_status 四档**：
confirmed / candidate / rule_only / unavailable（配 requires_auth 表示要登录）。

**pricing_kind**：
价是怎么来的：explicit_price / ratio_multiplier / tiered_expr / page_table / display_fork_price / group_price_map / subscription / auth_required / unavailable。

**new / changed / recovered / status_changed**：
价格事件四类：新出现、价格变化、恢复（消失又回来）、仅状态字段变价格没变。

**group_removed**：
连续 3 轮无数据移除旧价时发的事件，与普通「消失」区分。

**源站故障（is_origin_fault）**：
CF 520–526 判为站方源站宕机而非我方网络抖动，优先于传输错误判定。

**风控拦截页（_is_waf_block）**：
403/451 且是 WAF 页（cf-mitigated 头或 HTML）才触发换节点；API 层 403 JSON 不换。

## 存储与部署

**latest 快照（latest_key）**：
「站点:模型:分组」三元组的最新价快照，键拼法已收敛为唯一函数。

**documents 表**：
SQLite 里除价格/事件外所有 JSON 文档：catalog、settings、sanity_state、group_miss、discovery_ignored、model_probe、schedule_state 等。

**写库 / 写盘**：
把数据写入数据库 / 写入文件。
_弃用_：落库、落盘

**APP_TAG**：
`.env` 里的镜像标签=线上版本号（git 短 SHA），回滚=改回上一版。

**读接口封锁（内网令牌）**：
PRICE_WEB_INTERNAL_TOKEN 让 /api/* 只对 Next 服务端渲染和管理员会话开放，访客看页面拿不走 JSON。

**IAB**：
ZCode 内嵌浏览器；cookie 库是本地明文 SQLite，httpOnly cookie 可拷库直查取凭证。

**webblock**：
腾讯云对未备案域名的境内入口拦截（80 被 302 到 dnspod 页、443 握手后 RST），只有备案能解。

**去 AI 味清单**：
设计红线：衬线大字、发光渐变、彩色左竖线告警、假终端窗口等「AI 生成签名」一律不用。
